# Licensing notes

No distribution license is asserted by this package. Before inviting third parties to reuse the source, choose a license for the code you own and document third-party asset/data terms.

- Application code: developed for the project; the owner should choose the desired repository license.
- `public/penguin-traveler.png` and `public/panda.png`: generated for this project with ImageGen.
- `public/map-data.js`: copied from the original map project. Upstream geometry/city dataset provenance and a verified license were not recorded in the restored source. Preserve this note until that is resolved; do not invent attribution.
- `public/icon.svg`: inherited app icon.
- `docs/demo.png`: app screenshot generated with synthetic entries.

Current decision (Nov 2026): the public repository ships with **no licence** (all rights reserved) until the `map-data.js` source is confirmed. `hosted-reference/` is kept local and not published.

Repository visibility and a source-code reuse license are separate decisions. The included static deployment can be used as a public portfolio demo without granting an unverified blanket license over all source/data.
